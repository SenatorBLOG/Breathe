# Проект Breathe

**Breathe** — это современное веб-приложение для guided breathing и медитации. Работает прямо в браузере, без установки и регистрации (хотя есть опциональная авторизация).

### Основная идея
Пользователь взаимодействует с красивым glowing orb, который помогает выполнять различные дыхательные техники (Box Breathing, 4-7-8, Wim Hof, Belly Breathing и др.). Есть AI-коуч на базе NLP, который понимает состояние пользователя и предлагает подходящую практику.

### Ключевые возможности
- Интерактивный glowing orb для дыхания
- AI Coach (NLP-powered) — анализирует настроение и рекомендует техники
- Трекинг сессий, статистика, streaks и Calm Score
- Музыкальная библиотека для медитации
- Глобус с медитационными пинами пользователей по всему миру
- Google OAuth авторизация
- Темы оформления (night / day / nature)

### Стек технологий
**Frontend:**
- React + TypeScript
- Vite
- Tailwind CSS + custom theming system
- Three.js (для глобуса)

**Backend:**
- Node.js + Express
- MongoDB + Mongoose
- JWT + Google OAuth

**Деплой:**
- Frontend: Vercel
- Backend: отдельный сервер (планируется Render / Railway)

### Особенности
- Максимально минималистичный и спокойный дизайн
- Нет тяжёлых зависимостей, быстрый старт
- Фокус на UX и ощущение "спокойствия"
